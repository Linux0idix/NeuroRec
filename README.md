# NeuroRec — запись PvP-боёв для обучения нейро-ботов NeuroPvP

Клиентский мод для **Minecraft 1.21.11 (Fabric)**. Записывает твои дуэли в китах — что ты делал в бою
(удар, еда, жемчуг, кристалл, тотем, щит, отход…) и в какой ситуации (здоровье, дистанция, что в руке у соперника).
На этих записях учатся ИИ-боты сервера **NeuroPvP** (`mc.neuropvp.xyz`).

**Мод ничего не делает за тебя.** Это сборка «только запись»: в ней нет автопилота, авто-кликов, наводки и
сценариев — кода для этого в файле нет вообще. Играешь ты сам, мод только смотрит, как ReplayMod.

## Установка

1. Minecraft **1.21.11** + **Fabric Loader 0.18.4** или новее. Fabric API не нужен.
2. Скачай `neurorec-rec-*.jar` из [Releases](../../releases) и положи в папку `mods`.
3. В игре напиши в чат (с точкой, без `/`):
   ```
   .neuro key ТВОЙ_КЛЮЧ
   ```
   Ключ выдаёт администрация NeuroPvP. Мод ответит `✔ принят (ник)` — дальше просто играй.

## Команды

| Команда | Что делает |
|---|---|
| `.neuro` | что сейчас пишется: кит, решений, раундов, статус ключа |
| `.neuro on` / `.neuro off` | включить / выключить запись |
| `.neuro key <ключ>` | ввести ключ (проверяется на сайте сразу) |
| `.neuro upload` | отправить записи сейчас (обычно уходят сами каждые 3 раунда) |
| `.neuro tier HT3` | твой уровень (подсказка для сети) |

Подсказки появляются при наборе, как у обычных команд. Опечатки и русская раскладка (`ютугкщ`) понимаются.
Строка с твоим ключом никогда не уходит в общий чат.

## Что и куда отправляется

- Только данные боя: состояние и действие каждые несколько тиков, исход раунда, режим кита.
- Записи уходят на `https://mc.neuropvp.xyz/api/rec/upload` с твоим ключом, хранятся на сервере NeuroPvP
  и используются только для обучения ботов. Ники и записи не публикуются.
- Никаких паролей, файлов с компьютера и данных аккаунта мод не читает и не отправляет.

## Проверка файла

SHA-256 и ссылка на проверку VirusTotal — в описании релиза.
